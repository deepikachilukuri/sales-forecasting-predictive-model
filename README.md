# Sales Forecasting Predictive Model

## Project Overview

This project develops a predictive sales forecasting model using historical sales data and visualizes future predictions through an interactive Tableau dashboard.

## Objective

The goal of this project is to forecast future sales trends to support business planning and decision-making.

## Tools Used

- Python
- Pandas
- ARIMA Time-Series Forecasting
- Tableau Public

## Dataset

The dataset contains historical sales information with the following fields:

- Order Date
- Sales
- Category
- Region

## Predictive Model

An ARIMA time-series forecasting model was developed in Python.

The model predicts the next 12 months of sales and generates confidence intervals to represent forecast uncertainty.

## Project Files

- Sales_Forecasting_Model.ipynb - Python notebook containing data cleaning, model development, and forecasting
- superstore_sales.csv - Historical sales dataset
- forecast_results.csv - Forecast output containing predicted values and confidence intervals
